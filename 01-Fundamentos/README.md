# 🎯 Módulo 01: Fundamentos do Java

Este diretório reúne os conceitos iniciais e fundamentais da linguagem Java. O objetivo principal aqui é entender a sintaxe básica, manipulação de variáveis, operadores e a interação com o usuário via console.

## 📂 Conteúdo Praticado

### 1. [Variáveis e Tipos de Dados](./TiposPrimitivos.java)
Compreensão de que o Java é uma linguagem fortemente tipada. Prática com a declaração de dados na memória.
*   **Tipos Primitivos Inteiros**: `byte`, `int`, `long` (e o uso do sufixo `L`).
*   **Tipos Primitivos Decimais**: `float` (sufixo `f`) e `double`.
*   **Outros Tipos**: `char` para caracteres únicos e `boolean` para lógica.
*   **Classe String**: Manipulação de textos e cadeias de caracteres.

### 2. [Operadores](./Operadores.java)
Construção de lógicas e cálculos matemáticos básicos.
*   **Aritméticos**: Realização de contas (`+`, `-`, `*`, `/`, `%`) e o conceito de *casting* para divisões decimais.
*   **Relacionais**: Comparação de valores gerando resultados lógicos (`>`, `<`, `==`, `!=`).
*   **Lógicos**: Combinação de condições usando os operadores `&&` (E), `||` (OU) e `!` (Negação).

### 3. [Entrada de Dados](./EntradaDeDados.java)
Interação dinâmica com o usuário através do terminal.
*   Uso da classe `java.util.Scanner`.
*   Leitura de dados com `nextLine()`, `nextInt()` e `nextDouble()`.
*   **Boa prática**: Fechamento do fluxo de dados utilizando o método `.close()`.
