# 🔀 Estruturas de Controle

Nesta etapa da minha jornada em Java, estou aprendendo a controlar o fluxo de execução dos programas através das estruturas de controle.

## 📚 Conteúdos estudados

- [x] `if / else` — decisões condicionais
- [x] `switch` — múltiplas opções de decisão
- [x] `for` — estruturas de repetição com quantidade controlada
- [x] `while` — repetição baseada em uma condição
- [x] `do while` — execução garantida de pelo menos uma vez

## 🎯 Objetivo

Compreender como utilizar estruturas condicionais e de repetição para controlar o comportamento dos programas em Java.

- Operadores relacionais

- Controle do fluxo de execução
